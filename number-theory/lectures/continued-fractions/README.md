# Two 50-minute continued-fraction lectures

Prepared for Igor Rivin's introductory number theory course.

- lecture-1-matrix-fixed-points.pdf: continued fractions and matrix fixed
  points; 22 main slides, followed by 3 optional backup slides.
- lecture-2-lagrange-galois.pdf: why quadratic surds have repeating
  continued fractions; 30 main slides, followed by 7 optional backup slides.
- presenter-notes.pdf: 15 pages of suggested timings, explanations,
  exercise answers, pacing guidance, and references for both lectures.
- latex-source.zip: editable LaTeX sources and build instructions.
- source/: the same sources unpacked for browsing and editing in GitHub.

Each main lecture is budgeted for 50 minutes, including calculation
breaks and discussion. Stop at the exit question; the Further questions
slides are optional.

Lecture 2 proves Lagrange's converse before introducing Galois's
pure-periodicity criterion. The slides derive the conjugation rules,
the integer recurrence, the convergence sign argument, and the bounds
that force repetition. Lagrange's proof finishes on slide 20; an exercise
and recap follow, and Galois begins on slide 24. The notes also describe
how to spend the full session on Lagrange if more discussion is needed.

For Zoom, share the slide PDF window and keep the notes separate.
The PDFs work offline. No Canva connection is needed. The editable format
is LaTeX; this package does not include PowerPoint files.
